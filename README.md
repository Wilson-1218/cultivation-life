# 80億人修仙

當世八十億人都踏入修途。你是其中一個。這個網站用一輪可走完的推演，把靈根、壽元、靈石與名額攤開，看你落在哪一層。

它對齊的是 [80億分之1](https://1in8b.life/zh/) 那種體驗：開場是一個很大的分數，開局前有幾項可以不改就開始的選擇，接著一段一段往下走。四條狀態只提高可能性。關鍵處才停下。數字具體，語氣平。

文案是原創的凡人流修仙，不是任何一本小說的摘錄或角色導讀。

## 本機

```bash
npm install
npm run dev
```

開發伺服器聽在 `0.0.0.0:43117`。瀏覽器打開 [http://127.0.0.1:43117](http://127.0.0.1:43117)。

不需要帳號、資料庫或額外的金鑰。前世只留在這台瀏覽器裡。
